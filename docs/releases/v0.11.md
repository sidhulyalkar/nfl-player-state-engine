# v0.11.0 — Frozen Replay and State-Conditioned Opportunity

v0.11 strengthens the scientific loop around the v0.10 game simulator. The release does not promote a more complex production model. It makes the research system better at deciding which complexity deserves to be promoted.

## Added

- canonical expanding-week frozen replay across multiple seasons;
- weekly retraining cutoffs so each replay week learns only from earlier football;
- state-conditioned carry/target allocation challenger;
- oracle-state opportunity benchmark that isolates allocation from team-volume and play-call error;
- direct-vs-generative quantile blend calibrator using historical prediction rows only;
- per-position blend weights with minimum-sample fallback to a global weight;
- stricter multi-season research promotion gate;
- manual GitHub Actions historical benchmark workflow;
- benchmark summary endpoint in the guarded research API;
- v0.11 synthetic leakage, chronology, blend, and opportunity regression tests.

## State-conditioned allocation

The opportunity challenger starts from recency-weighted player share and adds shrunk evidence from red-zone, down, game-clock, score-state, distance, and field-position contexts. Sparse contextual evidence cannot dominate the base player role.

The head is deliberately **not** connected to production Monte Carlo player selection yet. It must first demonstrate better frozen allocation likelihood and opportunity MAE, then survive full pregame simulation replay after integration.

## Expanding benchmark

The canonical protocol is now:

```text
Week N model = all permitted information strictly before Week N
```

rather than fitting once before a long test window.

The benchmark retains separate scorecards for:

- play-call calibration;
- team play volume and pass rate;
- scoring environment;
- player carry/target allocation;
- fantasy quantile pinball loss;
- interval coverage.

## Blend laboratory

`QuantileBlendCalibrator` tests whether the direct player model and generative game model contain complementary signal. Blend weights are calibrated only on historical archived predictions. Current-week outcomes cannot influence their own blend weight.

No learned blend weight changes production projections automatically.

## Promotion boundary

A v0.11 candidate fails closed unless evidence spans multiple seasons and hundreds of games, core metrics remain robust across weekly folds, the opportunity challenger beats static share, and downstream fantasy calibration does not regress.

Even after all automated gates clear, manual champion review remains required.

## Next evidence-driven branches

The benchmark should decide the next implementation:

- team-volume miss -> pace/drive model;
- allocation miss -> integrate state-conditioned allocator, then routes/personnel/alignment;
- efficiency miss -> decomposed pressure/completion/air-yards/YAC/rushing outcome heads;
- game-script transition miss -> persistent drive-level latent strategy state.

This ordering is intentional. v0.11 should make the project harder to fool with an attractive but unproven football idea.
