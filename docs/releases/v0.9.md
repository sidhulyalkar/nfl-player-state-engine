# v0.9 — Ranking Calibration & Evidence Fusion

v0.9 makes league-specific ranking correctness observable and testable instead of assuming that roster-aware VORP alone is sufficient.

## Production corrections

- League scoring is applied before replacement levels and VORP whenever component stat quantiles or already-scored league simulation quantiles are available.
- Generic `season_points_q10/q50/q90` remains a supported compatibility path, but rows are explicitly marked `generic_points_fallback` and exposed through the API/UI.
- The roster marginal-value simulator prioritizes the same league-scored quantiles used by valuation.
- The modern `espn-api` `position_slot_counts` and list-based scoring configuration are normalized correctly.
- `OP` and related aliases normalize to superflex.
- Unsupported live scoring rules remain visible in snapshot provenance instead of being guessed.
- The base Product API and Draft War Room now share `league_config_from_snapshot()` so waivers, lineups, trades and draft valuation cannot interpret the same league differently.
- Model-facing GSIS/canonical player IDs are preferred in structured role evidence and draft roster reconstruction.

## Ranking calibration

External rankings are **challenger/audit data, not truth**.

The canonical ranking snapshot schema stores:

- source and source kind;
- player identity and identity-match confidence;
- ranking type;
- team count, scoring and QB format;
- rank, positional rank, range, standard deviation and expert count;
- source weight;
- UTC capture timestamp;
- source URL.

Supported source registry includes FantasyPros, nflverse ffverse rankings, Fantasy Life, ESPN, RotoWire, PFF, Rotoworld, Sleeper, Yahoo, NFFC, FFPC and Underdog. Automation is only enabled where a maintained API/data client exists. Licensed or manual exports are preferred to brittle scraping.

The official FantasyPros v2 API integration supports consensus/ADP snapshots and expert-accuracy metadata when `PSE_FANTASYPROS_API_KEY` is configured.

## Dynamic scarcity challenger

The production v0.8 live score remains authoritative in v0.9.

A new unpromoted challenger adds:

- remaining positive-VORP supply by position;
- expected same-position players taken before the next turn;
- expected position supply at the next pick;
- probability-weighted value of the best alternative likely to survive;
- positional wait loss;
- dynamic scarcity score;
- challenger rank and delta versus production.

This avoids redefining scarcity as a within-position percentile. The challenger is intentionally prevented from changing `draft_action` until frozen historical draft replay shows better roster utility.

## Format robustness benchmark

`src/player_state_engine/evaluation/ranking_validation.py` and `scripts/build_format_ranking_benchmark.py` evaluate the same player pool across:

- 8-, 12- and 14-team leagues;
- 1QB, 2QB and superflex;
- standard, half-PPR and PPR;
- TE premium;
- expanded 8-team starting lineups.

Validation includes:

- structural monotonicity;
- Spearman and Kendall rank agreement;
- rank MAE;
- top-12/24/50 overlap;
- model-versus-external rank movement when the format changes;
- scoring exactness coverage;
- an explicit promotion gate.

A challenger does not promote merely because it correlates with experts. Historical roster-utility replay is required by default.

## Historical ranking replay

`draft_ranking_replay.py` compares policies on identical frozen candidate sets and reports:

- mean/median/total utility;
- q10/q90 utility;
- oracle regret;
- candidate improvement over the production baseline.

Point-in-time candidate availability and point-in-time model inputs are required. Final-season data must never leak into the decision set.

## Evidence fusion

News is no longer treated as generic bullish/bearish text.

Unstructured evidence is classified as:

- OFFICIAL
- DIRECT_OBSERVATION
- REPORTED
- COACH_QUOTE
- PLAYER_QUOTE
- ANALYSIS
- SPECULATION

Claims update football latent states such as availability, starter security, route participation, target share, carry share, goal-line role and third-down role with source-aware decay.

Structured nflverse injuries, depth charts and snap counts bypass sentiment extraction and become direct role-state evidence.

`download_nflverse(..., include_intelligence=True)` can additionally archive injuries, ffverse player IDs, ffverse rankings and fantasy opportunity data as fail-soft evidence streams.

## Research two-turn planner

`POST /v1/leagues/{league_id}/draft/plan` exposes a research-only two-turn survival lookahead. It compares taking each candidate now plus the value likely to remain at the next turn.

It is stamped `promoted: false`. Opponent roster branches are not yet fully reoptimized, so it cannot override the production best-pick-now result until replay evidence clears the same promotion discipline.

## Product API

New endpoints:

```text
GET  /v1/rankings/sources
GET  /v1/leagues/{league_id}/rankings/audit
POST /v1/leagues/{league_id}/draft/plan
```

The War Room shows scoring exactness, dynamic wait loss, external consensus/disagreement and the research lookahead while keeping Python as the numerical authority.

## Promotion rule

A ranking challenger earns production authority only after:

1. no hard structural format check fails;
2. league scoring provenance is understood;
3. frozen historical draft replay improves roster utility over production;
4. oracle regret does not worsen materially;
5. external format-delta behavior is used as a diagnostic, never the objective;
6. CI and deterministic regression tests pass.
