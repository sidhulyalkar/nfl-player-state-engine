# v0.12 — Simulated-State Opportunity & Factorial Error Attribution

v0.12 moves the state-conditioned carry/target model from an oracle-state diagnostic into the actual Monte Carlo state machine, but only as an opt-in research challenger. The production projection path remains unchanged.

## Why this release exists

v0.11 answered an isolated question: if the real play-state sequence is known, can situational context improve player opportunity allocation over static recent share?

That is not enough for deployment. A pregame model has to survive errors in the simulator's own state distribution. v0.12 therefore evaluates four combinations at every frozen weekly cutoff:

| Variant | Play call | Player allocation |
|---|---|---|
| `profile_static` | point-in-time team/opponent prior | static usage share |
| `learned_static` | learned run/dropback model | static usage share |
| `profile_state` | point-in-time team/opponent prior | state-conditioned allocator |
| `learned_state` | learned run/dropback model | state-conditioned allocator |

Every cell uses the same pre-cutoff evidence, empirical play-outcome model, matchup, usage state, and simulation seed. This creates a factorial experiment rather than a pile of inseparable model changes.

## Major implementation changes

### Simulated-state allocation

`simulate_matchup(...)` accepts an optional `StateConditionedOpportunityModel`.

For each simulated carry or target it conditions on the simulator's current:

- down;
- distance;
- field position;
- red-zone state;
- clock;
- leading / neutral / trailing score state.

The allocator is restricted to player IDs present in the point-in-time usage pool for the team. Historical players who are no longer represented in current usage cannot receive simulated work merely because they remain in the model's training history.

### Opportunity is now measured from the actual Monte Carlo draws

The simulator records `carries` and `targets` in every player draw. Replay evaluation aggregates those draws directly.

This fixes an important v0.11 limitation: full-game opportunity evaluation previously reconstructed expected work as team volume multiplied by static usage share, so it could not faithfully measure a state-conditioned allocator.

### Recall-safe player opportunity scoring

Player opportunity evaluation now joins predicted and observed player rows with an outer join and fills the missing side with zero.

A simulator can no longer avoid penalty by completely missing a player who received real work, or by creating meaningful work for a player absent from the observed outcome.

The report additionally exposes observed-player coverage.

### Context ablations and negative control

The factorial benchmark also runs cheap oracle-state allocation diagnostics:

1. static share;
2. red-zone-only context;
3. full context;
4. full context with each context family removed;
5. full context after context labels are permuted within team-season.

The permutation keeps chronology, team, player identities and base opportunity counts intact while breaking the relationship between play state and context. A useful context model should beat this negative control.

### Research-only promotion gate

The v0.12 state-allocation gate is deliberately narrower than production promotion. It only decides whether the state-conditioned allocator should become the research generative champion.

It requires:

- at least three held-out seasons;
- at least 200 replay games;
- improved full-pregame player opportunity MAE;
- no material carry or target regression;
- no fantasy pinball regression;
- sufficient weekly opportunity win rate;
- full context beating both static share and the permuted-context negative control.

Even if this gate clears, `production_projection_changed` remains false.

## Claim boundary

v0.12 implements the experiment required to determine whether state-conditioned opportunity survives a complete pregame simulator. It does not claim that it does.

The real 2023-2025 factorial replay should decide whether v0.13 focuses on richer player role evidence, pace/drive volume, decomposed play outcomes, or simply more point-in-time evidence coverage.
