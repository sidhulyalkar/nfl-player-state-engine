# v0.10 - Game Intelligence & Play-by-Play Simulation

## Release goal

Move the project from player distributions conditioned on coarse game context toward an auditable **generative football-game challenger** that can explain where player opportunity comes from.

## Implemented

### Evidence and state

- point-in-time PBP normalization;
- offense and defense tendency snapshots;
- cross-season recency-weighted player usage;
- optional play-structure context from FTN/participation inputs;
- explicit live/fail-soft/retrospective/manual evidence classes;
- acquisition manifests;
- timestamp-ready coaching/play-caller registry template.

### Models

- regularized probabilistic run/dropback challenger;
- transparent opponent-conditioned matchup prior;
- heavily shrunk direct play-caller matchup residual;
- hierarchical empirical conditional play-outcome sampler.

### Simulation

- score/clock/possession/down/distance/field-position state machine;
- run/dropback selection;
- fourth-down go/field-goal/punt decisions;
- first downs, turnovers and touchdowns;
- target/carry/passer allocation;
- correlated raw player stat draws;
- exact league fantasy scoring through `LeagueConfig`;
- reproducible seeded simulation draws;
- explicit research limitations and provenance.

### Evaluation

- play-call log loss, Brier score, AUC and calibration;
- team play-volume/pass-rate/points replay metrics;
- player carry/target opportunity metrics;
- fantasy pinball loss and q10-q90 interval coverage when completed player outcomes are supplied;
- frozen multi-game historical replay;
- transparent matchup-profile baseline;
- strict fail-closed promotion gate.

### Continual learning

- weekly candidate build;
- recent-game replay;
- model/data SHA256 manifest;
- Git SHA and cutoff tracking;
- research registry;
- scheduled/manual GitHub Actions evidence generation;
- no automatic production promotion.

### API

- `GET /v1/research/game-intelligence/sources`
- `GET /v1/research/game-intelligence/status`
- `POST /v1/research/game-intelligence/simulate`

All surfaces are explicitly research-only until promotion criteria are met.

## Core operating rule

The simulator is a challenger to the existing player projection engine, not its replacement.

A release can contain a functioning simulator without claiming that simulated fantasy scores are more accurate. Promotion requires frozen replay evidence.

## Known research limitations

- overtime is not yet modeled;
- PAT/two-point decisions are simplified;
- fourth-down policy starts from transparent heuristics;
- player allocation starts with recency-weighted usage instead of a personnel/route model;
- the empirical outcome model does not yet condition on full offense/defense/player latent quality;
- current formation/personnel evidence availability is not uniform enough to promote those features live;
- coach-vs-coach samples are too sparse to carry substantial weight;
- no direct production blend between game-simulation distributions and champion player quantiles is promoted.

## Promotion target

The next milestone is not `more simulator complexity`. It is a broad historical benchmark showing where the simulator beats or loses to the existing champion.

Only after that should the project consider:

1. learning player opportunity conditional on simulated state;
2. formation/personnel transition models;
3. defensive response states;
4. sequence/drive latent models;
5. an empirically weighted ensemble between direct and generative projections.
