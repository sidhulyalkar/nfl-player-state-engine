# UI information architecture

## Global shell

- Persistent league selector
- Persistent manager/roster selector
- Current week and projection timestamp
- Data freshness indicator
- Gemini Copilot drawer
- Search command palette

## Navigation

1. Command Center

6. Lineup Lab
7. NFL State
8. Model Lab

## Visual language

- Dark analytical canvas with restrained accent colors
- Dense information without spreadsheet claustrophobia
- Probability bands, fan charts, and small multiples instead of decorative gauges
- Ownership and availability visible in every player list
- Reason codes beside recommendations
- Warnings for stale, missing, or low-confidence inputs
- Accessible contrast and keyboard navigation

## Canonical visualizations

- Player fan chart across future weeks
- Opportunity funnel
- Role trajectory stacked area chart
- League positional-strength heatmap
- Trade before/after radar and delta waterfall
- Roster Monte Carlo outcome histogram
- Team system fingerprint
- Calibration reliability plot
- Source freshness timeline
- Network graph of player ownership and trade compatibility, used sparingly

## Responsive behavior

Desktop is the primary analysis surface. Mobile should prioritize:

- lineup decisions;
- injury alerts;
- waiver shortlist;
- trade review;
- concise player cards;
- Copilot conversation.
